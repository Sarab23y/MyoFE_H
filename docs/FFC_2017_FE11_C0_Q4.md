# FFC 2017 `FE11_C0_Q4` compatibility correction

## What the compiler error means

`FE11_C0_Q4` is an FFC-generated finite-element basis lookup: element/coefficient
slot 11, component 0, evaluated at a four-point quadrature rule.  The failing
C++ kernel uses that table while assembling a variational projection, but the
FFC 2017 generated translation unit never declares it.  This is a code-generation
failure, not a NumPy warning or a nonlinear-solver result.

The hash alone cannot be mapped back to a Python source line without the
generated reproduction directory.  Source inspection identifies the risky
form family: projecting expressions containing `p`, the symbolic CG1 pressure
component of the mixed CG2/CG1 mechanics Function, into a Quadrature or output
space.  That combination requires FFC to tabulate a mixed-coefficient basis and
matches the missing-table signature.  It occurred in mechanical-health
pressure/constraint/total-stress evaluation and output-only total-stress forms.

## Correction

All maintained scalar Quadrature projections now explicitly select FFC 2017's
`quadrature` representation and degree two, with a stable field label printed
before the first compile.  A remaining failure therefore identifies its field.

Pressure is handled more narrowly: the CG1 pressure subfunction is extracted
from the mixed solution as a concrete Function and interpolated at the existing
material points.  No variational form containing the symbolic mixed pressure is
compiled.  The incompressibility fiber stress is then evaluated from the exact
production identity

`S_inc,ff = -p * f0 . C^-1 . f0`.

Xi, ground, collagen, and active fiber components are evaluated with the same
degree-two material-point projection, and diagnostic totals are reconstructed
by their production additive identities.  This affects recording only.  The
weak form, constitutive tensors, active mechanics, and DG1 MyoSim feedback are
unchanged.

The source evidence is strong, but cluster confirmation is still required.
The extended validator now compiles CG2-displacement mixed-coefficient stretch,
J, and inverse-C forms and safely interpolates a CG1 pressure subfunction.  The
200-step smoke launcher creates `ECM_output_smoke_${SLURM_JOB_ID}` so failed or
successful historical jobs are never overwritten.
